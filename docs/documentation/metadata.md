# Metadatas

Metadatas are also intended for integration into third-party web applications. You can achieve this in three different ways:

| Description | Example |
|-------------|----------
| Json | https://localhost/api/metadata/swiss_municipalities/ |
| Html | https://localhost/api/metadata/swiss_municipalities/html/   |
| Html simple (no images)| https://localhost/api/metadata/swiss_municipalities/html_simple/  |
